## 4. 시스템 관리 모듈만 개발 및 배포

- 관리자(시스템 관리) 모듈은 별도 앱(`admin/` 또는 별도 저장소)으로 두고, 해당 앱만 개발·빌드·배포하는 구성을 권장합니다.
- **개발**: `admin/`에서 `npm run dev` (필요 시 포트 3001 등)
- **빌드**: 해당 디렉토리에서 `npm run build` → `.output` 또는 `dist` 생성
- **배포**: 빌드 결과만 Nginx 문서 루트 또는 별도 location(/admin 등)으로 서비스

**상세**: [README_04_시스템관리모듈만개발및배포방법.md](./README_04_시스템관리모듈만개발및배포방법.md)

## 5. 로컬 Windows에 Nginx 설정하기

- **다운로드**: nginx.org에서 Windows용 Stable 버전 다운로드 후 압축 해제 (예: `C:\nginx`)
- **정적(SSG)**: Nuxt `generate` → `.output/public`를 Nginx `root`로 지정, `try_files $uri $uri/ /index.html`
- **SSR**: Nuxt `build` 후 `preview`(또는 Node로 서버 실행) → Nginx에서 `proxy_pass http://127.0.0.1:3000`
- **실행**: `nginx.exe`, 재로드 `nginx -s reload`

**상세**: [README_05_로컬윈도우에Nginx설정하기.md](./README_05_로컬윈도우에Nginx설정하기.md)

## 6. NGINX에 배포하기

- **SSG**: `npm run generate` → `.output/public`를 서버 문서 루트에 업로드, Nginx에서 정적 서빙 + `try_files`로 SPA 대응
- **SSR**: `npm run build` → `.output` 업로드 후 Node로 서버 실행(PM2 등), Nginx에서 해당 포트로 `proxy_pass`
- **HTTPS**: certbot 등으로 SSL 설정 권장

**상세**: [README_06_NGINX에배포하기.md](./README_06_NGINX에배포하기.md)
